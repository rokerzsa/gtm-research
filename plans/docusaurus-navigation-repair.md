# Docusaurus company containment and pagination repair

12 November 2026. User reported UpGrad content outside its company root and requested project-local authoring rules. This is a site-integration correction, not new company research or publishing authorization.

## Confirmed defects

`sidebars.ts` curated two company categories, then spliced an autogenerated slice of each remaining `book/` directory into that same top-level array. An autogenerated slice emits the selected folder's children. It did not create an UpGrad wrapper; the book-root `_category_.json` could not supply that omitted parent. As a result, the UpGrad introduction and its commercial-strategy category were peers of the company roots.

All books also belonged to `researchLibrary`. Docusaurus generates pagination from sidebar membership/order. Inspected generated UpGrad introduction metadata explicitly set Previous to RedyHire's final evidence-notes page; RedyHire's final page had Next pointing to UpGrad. This was a real reading-boundary error, even though every URL existed and the build passed. The old project validator checked IDs/links/headings/compiled targets, not ancestry or expected pagination, so it did not detect these defects.

Relevant primary documentation: [autogenerated sidebar slices](https://docusaurus.io/docs/sidebar/autogenerated), [sidebar association and pagination](https://docusaurus.io/docs/sidebar/multiple-sidebars). These framework rules informed the repair; the exact failure was established by this repository's code and generated metadata.

## Applied architecture

- `research-library.json` owns company metadata and the explicit ordered chapter trees. Both the home page and sidebars consume this registry through `src/data/researchLibrary.ts`.
- Each company has a distinct sidebar and a company-root category linked to its introduction. A library return link and the navbar's Research link lead to the site home. No chapter doc is assigned to two companies.
- HackerRank's curated sequence is retained. Three existing supporting landing pages retain their URLs, appear as supplemental refs under HackerRank, and declare its sidebar explicitly. They do not interrupt sequential chapter pagination. No research prose or acceptance state in those books was rewritten.
- Existing chapter URLs are preserved. Operational project/workspace indexes, source/claim/review records and archives stay outside the Docusaurus include patterns. Broken Markdown links now fail the build.
- Root `AGENTS.md` now defines the site/workspace/project/book index roles, registration, source paths versus generated IDs/routes, company containment, sequencing, supplemental pages and required checks. Existing sandbox guidance is preserved.
- `README.md` documents registration and commands. Type checking now loads the theme declarations and explicitly handles the installed Docusaurus baseUrl configuration's TS6 deprecation; the home component uses an explicit React return type.
- The existing Pages workflow now runs typecheck and build/navigation verification before upload. Workflow triggers and deployment permissions are unchanged; no workflow was triggered by this task.

Project-local rules belong in AGENTS.md/registry rather than embedding this site's Docusaurus implementation into the portable research skill. Pre-existing skill edits were left intact.

## Actual verification

`npm run check:library` passed (production build followed by verifier); `npm run typecheck` passed. The enhanced `npm run verify:library` then passed its additional rendered-sidebar and flat-root negative-control checks.

The verifier reads the generated plugin metadata and compiled HTML rather than trusting the source tree. It checks all 31 included pages: HackerRank 15, RedyHire 7, UpGrad 9. Tests cover company ancestry, actual sidebar association, exact registered Previous/Next sequence, introduction/final-page boundaries, supporting-guide isolation, all included pages registered once, stable book-root routes, home entries and operational-page exclusion. The rendered HTML sidebar must contain the owning company and no other company's chapters. Negative controls reproduce both a flat-root slice and a foreign Previous link and must be rejected.

Result: UpGrad's introduction has sidebar `upGradBook`, no Previous and Next pointing to its complete-GTM chapter. Its last evidence-notes page has no Next. The same boundary conditions hold for the other books. Retained machine result: [library-navigation-validation.json](library-navigation-validation.json).

No browser screenshot/responsive-layout or live-deployment pass claimed. This repair verifies generated hierarchy/pagination/HTML and types. Prior unsuccessful preview attempts remain disclosed separately; the current fix does not depend on a preview server. No deployment or push performed.
