# Increment 3 — Static Review Checklist

[Book home](../book/index.md) · [Chapter 03](../book/part-02-investigation/03-research-contracts-and-investigation.md) · [Chapter 04](../book/part-02-investigation/04-evidence-and-source-integrity.md)

**Method:** Static file, instruction, template and link inspection only. No live investigation, Codex execution, source verification or paid access is implied. Report each check as passed/failed/qualified in the delivered static-review report.

- [ ] Existing standalone architecture and Increment 1–2 charter/plan approval hierarchy remain unchanged.
- [ ] `SKILL.md` accurately describes Increment 3 capability and later-increment stop gates.
- [ ] Authorized contract + charter + high-level + detailed plan and actual approval records are verified **before** substantive investigation.
- [ ] Research is question-driven and depth-first; independent alternative explanations and contradictions can be investigated.
- [ ] Source register distinguishes discovered, directly inspected, partial, snippet and third-party descriptions; publication and event dates are separate.
- [ ] Original information lineage and copies are marked; repeated media reports are not counted as independent confirmation.
- [ ] Claim register separates observations, reported assertions, historical propositions, interpretations and causal hypotheses.
- [ ] Supporting and contradictory evidence with stable source references are retained.
- [ ] Four qualitative confidence levels with rationale are present, with no mandatory numeric score.
- [ ] Evidence state and review state are distinct from record lifecycle and research execution.
- [ ] Major conclusion review remains `pending`; no fictional red-team pass, closure dossier, or project completion.
- [ ] Bounded legitimate source recovery and explicit inability to inspect originals are specified.
- [ ] Source, claim and gap IDs use project ledger; `K` uses workspace counter; ID issuance is monotonic and durable.
- [ ] Provenance→claim→concept links survive registry splits via canonical identities/lookup references.
- [ ] Important provisional findings persist during investigation; record presence is not truth acceptance.
- [ ] Gap criticality is consequence-based and independent from difficulty or budget.
- [ ] Evidence-exhaustion closure is permitted only for justified **noncritical gaps**, not subphase closure.
- [ ] Critical gaps require escalation and selective pause when dependent assumptions are invalidated.
- [ ] Investigation journal captures meaningful chronological work and failed avenues without being a duplicate evidence register.
- [ ] Substantive writes, indexes and journal precede checkpoint advancement; ambiguous state halts affected writes.
- [ ] R-01–R-08 safeguards remain consistent, especially hard limits, unavailable workspace and critical reviews.
- [ ] Full Chapters 03–04 are present, substantively complete and navigable from book/part indexes.
- [ ] Template examples contain placeholders, not fabricated real company facts, approvals or access.
- [ ] Existing internal Markdown links resolve, including new reference and book navigation.
- [ ] DR-001–DR-052 primary coverage remains exactly 52 unique entries.
- [ ] Later increments 4–6 remain explicitly incomplete; no live research, skill installation or workspace initialization is represented.
- [ ] ZIP archive is complete, matches staged files and passes integrity check.

**Release note:** Passing static checks is not proof of reliability in a running Codex installation. Further implementation approval gates remain mandatory.
