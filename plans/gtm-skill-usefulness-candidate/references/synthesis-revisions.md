# Evidence-led selective revisions

[Book architecture](research-book-architecture.md) · [Revision template](../templates/synthesis-revision-log.md)

Revise affected claims, reviews, concepts and chapters when new evidence changes a meaningful interpretation. Preserve prior material wording/versions, reason, source references, confidence/review effect and downstream links. Cosmetic edits need no elaborate revision dossier.

Changing interpretation, emphasis or chapter structure to answer the same approved objective is autonomous. Add/reorder/merge deeper chapters and update the whole-company overview as findings require; do not freeze the initial outline or request routine reapproval. A genuinely new subject/objective, hard-limit increase or external action needs applicable authority.

Persist source/claim/review changes before derived prose; revisit affected causal conclusions rather than merely appending a source summary. Maintain the canonical overview and deep-dive links, public citation targets, archives outside publication and checkpoint last. An evidence correction is not a fabricated new approval or permission to overwrite history.

For existing completed projects preserve prior dossiers and use [selective reopening](dependency-impact-and-reopening.md). No automatic migration or unrequested monitoring/publication is implied.
