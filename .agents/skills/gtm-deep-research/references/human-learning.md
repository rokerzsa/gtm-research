# Upfront participation choice and final review

[Discovery](goal-discovery-and-charter.md) · [Completion](completion-and-acceptance.md)

Ask upfront whether learning updates are wanted. During autonomous research, default to concise nonblocking progress updates and defer deep learning discussions until delivery. Do not insert quizzes, chapter signoffs or phase approval requests into an approved autonomous run. User-requested questions during work receive an answer and work continues unless the user asks to stop.

Deliver after internal coverage, strategy, evidence and editorial checks, explicitly ready for user review. The user can then review the overview and deeper chapters one at a time, challenge interpretations and request revisions. Reuse existing evidence and covered authorization; investigate genuine in-scope gaps and preserve revisions. Ask only if feedback introduces a genuinely new objective, external action or hard-limit change.

Optional learning exchanges explain the case's decision, mechanism, alternatives and discriminating evidence. Do not record unprovided learner answers or treat agreement as evidence. Do not import the user's own business, industry or strategy without a separate request. Comprehension, claim confidence, internal readiness and user acceptance are distinct states.

Use [learning notes](../templates/learning-checkpoint.md) only when useful, not as mandatory workflow output. Pending learning discussions do not block unrelated authorized work.
