## Validate behavior as well as structure

Reconcile entrypoint, references, templates and live specification after amendments; historical review artifacts do not validate new behavior. Validate frontmatter, references and actual authority/identity/recovery invariants. Exercise realistic bounded scenarios for intake, strategic/current coverage, adaptive GTM chapters, hard limits, future uncertainty and final review. Report actual tests and limitations; static inspection is not runtime proof. Installation, packaging and publishing are separate tasks only when requested. Do not impose a ZIP/release ceremony on an authorized local skill edit.

Detailed governing procedure: [operational guidance](../../references/final-static-audit.md). Strategy/current-state requirements: [coverage procedure](../../references/strategy-and-current-state.md).

Use the procedure's [usefulness evaluation cases](../../references/final-static-audit.md#usefulness-evaluation-cases) to test both generic analysis and unsupported specificity. Set expected dispositions before comparing actual outputs; disclose same-investigator review and evaluated scope. A useful episode or clean link check does not establish whole-book or autonomous research reliability.
